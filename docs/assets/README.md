# Logentra OS brand assets

Official mark: concept D, a sharp L cut from a rounded square (the stencil plate).

- Light plate: `#4F46E5` → `#4338CA`
- Dark plate: `#22D3EE` → `#0891B2`
- Tagline: “The logbook that stays yours.”

Use the icon SVGs or matching PNGs in the product UI, favicon, and app icon. Use the horizontal lockup in headers, GitHub, and docs. Do not recolour the plate, outline the mark, or change the L cutout.

These files are copied from the official logo package. The served app also ships `ui/static/favicon.ico`, `ui/static/favicon.svg`, and `ui/static/apple-touch-icon.png`.
